# 黑边适配

资源包中的独立 C# custom 任务，通过公开 CustomController 接口裁剪上下黑边并校正点击，无需修改 UI 或替换框架 DLL。

桌面端将“剪裁上下黑边以适配标准比例”放在队列最前面，与日常任务一起运行。适用于居中的 16:9 内容，例如 2560×1600 → 2560×1440；标准 16:9 画面直接通过。

关闭任务内开关后运行一次或重启工具恢复；普通重连可能复用控制器并保留适配。黑边不符合预期时停止截图和坐标输入，恢复画面或重启工具后重试。运行中勿调整窗口大小；实时预览可能仍显示黑边。

验证（Windows，.NET 10）：

```sh
dotnet test tests/Letterbox.Tests/Letterbox.Tests.csproj -c Release
```

覆盖裁剪、点击/滑动映射、异常画面、任务启停、并发、多实例和资源释放。加载发布的任务配置，使用模拟画面与自建隐藏窗口，不操作游戏。
